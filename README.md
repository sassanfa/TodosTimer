# Todos Timer

**ابزار کمکی مدیریت زمان** با شمارش معکوس، هدف‌گذاری، ثبت زمان، گزارش CSV و تقویم شمسی.

طراحی و توسعه: **SassanFa**

## اجرا

فایل `index.html` را در مرورگر باز کنید. برای استفاده از تقویم، از پیوند «تقویم» در سربرگ برنامه وارد `calendar.html` شوید.

برنامه به نصب وابستگی یا فرایند build نیاز ندارد. برای میزبانی روی GitHub Pages، هر سه فایل `index.html`، `calendar.html` و `README.md` را در ریشهٔ مخزن قرار دهید و GitHub Pages را برای شاخهٔ موردنظر فعال کنید.

## امکانات

- تایمر با عنوان فعالیت، حالت روز و شب، تمام‌صفحه و آلارم قابل انتخاب
- افزودن تایمر دوم و اجرای آن پس از پایان تایمر اصلی
- ذخیرهٔ سوابق در مرورگر و مشاهدهٔ مجموع زمان هر عنوان
- خروجی و ورودی CSV برای سوابق تایمر
- تقویم شمسی، نمودار زمان‌ها، ثبت دستی فعالیت و پشتیبان‌گیری JSON

## ذخیره‌سازی و حریم خصوصی

سوابق در فضای ذخیره‌سازی محلی همان مرورگر نگه‌داری می‌شوند و برنامه آن‌ها را به سرور ارسال نمی‌کند. پاک‌کردن داده‌های مرورگر ممکن است سوابق را حذف کند؛ برای نگه‌داری یا انتقال آن‌ها از پشتیبان‌گیری صفحهٔ تقویم استفاده کنید.

فونت‌های وب در صورت دسترسی به اینترنت از Google Fonts بارگیری می‌شوند؛ در غیر این صورت فونت جایگزین دستگاه استفاده خواهد شد.
